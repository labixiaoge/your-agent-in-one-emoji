One emoji that stands for my AI agent: 🕸️ — a spider web. The agent works like a spider at the centre of a web: eight wallets, parallel subagents and a sweep every two hours, all threads reporting back to one place, catching bounties as they land in the net. It reads in an instant, it is specific to how the agent works, and it is nowhere near the obvious robot or smiley.

## Run it

```sh
python3 main.py
```

This writes the single emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
